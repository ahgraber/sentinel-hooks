Probe: a standalone plugin in Sentinel's layout (root plugin.json, com.github.copilot/hooks/hooks.json), installed from
a local marketplace into a separate COPILOT_HOME. Its hook printed Sentinel's ask output for any call naming notes.txt:
  {"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "ask", "permissionDecisionReason": "Probe: the hook asks about notes.txt."}}
and allowed every other call. Prompt: create notes.txt containing hello with the file-creation tool, one attempt, no shell.
The user answered No to any prompt about notes.txt.

  The hook answered ask to Write notes.txt. Copilot CLI showed the user a prompt; the user answered No.
  notes.txt: not created.
  This probe's hook matched only a file path, so it answered ask to the one Write call.

Result: in assisted mode, Copilot CLI's model reviewer decides a hook's ask, and a hook's ask does not reach the user.
`--assisted-approval` is accepted only in non-interactive prompt mode; an interactive session takes assisted mode
from defaultPermissionMode.
In autopilot mode, and in a non-interactive allow-all run, Copilot CLI denies a call a hook asked about.
In an interactive allow-all session, a hook's ask reaches the user.
